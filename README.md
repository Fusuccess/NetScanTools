# NetScanTools

本机图形化网络工具，打包为 macOS 与 Windows 桌面应用。

用于扫描自己有权限的网络：发现局域网主机、探测指定 IP 的端口、建立 SSH 隧道，以及把本机入口端口映射到目标地址。

## 功能

| 模块 | 说明 | 计划 |
|------|------|------|
| 局域网扫描 | 手动指定网段，列出在线设备（IP、主机名、同网段 MAC 等） | 一期 |
| 端口扫描 | 对指定 IP 做 TCP 端口探测，范围可手填，不限局域网 | 一期 |
| SSH 隧道 | 对应 `ssh -NfL` 本地端口转发，支持密码和私钥 | 一期 |
| 设备画像增强 | mDNS / UPnP / SNMP 等，尽量补名称与型号 | 二期 |
| SSH 扩展 | 远程转发、动态代理、断线重连 | 三期 |
| 本机端口映射 | 选定入口 IP:端口，转发到目标 IP:端口（不经 SSH） | 四期 |

设备名称、型号按「能拿到就展示」处理，不保证每台设备都有完整信息。

## 技术栈

- 界面：Tauri 2 + React
- 本机逻辑：Rust（扫描、SSH、端口映射）
- 打包：macOS `.dmg` / `.app`，Windows `.exe` / `.msi`

不捆绑 nmap。一期用 TCP 全连接 + ICMP + 本机 ARP 表完成探测。
